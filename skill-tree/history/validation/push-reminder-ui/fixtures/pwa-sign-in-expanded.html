Sign in with Habitica

Use the User ID and API Token from Habitica settings. Your token works like a password, so it stays private and is used only to talk to Habitica.

Where to find them
  1. Website: User icon menu -> Settings -> API.
  2. Android: Settings -> API.
  3. iOS: Settings -> Account Details.
  4. Copy User ID and API Token into this form.
Open Habitica API settings
Safety model
  • Your API Token is a password. Keep it private.
  • Sign in sends credentials only to Habitica for account data.
  • Sign in and refresh read data; Habitica-changing actions are explicit.
  • Session-only sign-in is the default.
  • Remembering credentials is optional and stored only in this browser.
  • Credentials are never saved in exports, app messages, or device sync.

Sign out ends the current tab session. Clear local data removes saved credentials and saved app data. Privacy and data handling

Use Companion as an app

Install on iPhone

Open Habitica Companion from your Home Screen in its own window.

  1. Open this Companion website in Safari.
  2. Open Share, from the page menu or toolbar, then choose Add to Home Screen.
  3. Leave Open as Web App enabled when Safari offers the option, then tap Add.
  4. Open Habitica Companion from the new Home Screen icon.

If sign-in or saved data is absent in the installed app, sign in there again. Safari and the installed app may use separate storage.

Sign-in remains session-only unless you explicitly choose Remember credentials on this device. Closing the app may end a session-only sign-in. Installation does not save credentials or enable notifications.

Open the app online once before trying offline startup. Cached screens can show saved data; refreshing, signing in and changing Habitica still need a connection. Browser storage can be unavailable or cleared.
