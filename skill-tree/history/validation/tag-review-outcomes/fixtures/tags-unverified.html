Project and group tags

Connect categories, projects, sections, labels, goals and saved lists to native Habitica tags. Each linked task keeps its own Habitica record. Tag metadata gives no experience, gold or completion rewards.

Tag access is optional and separate from workspace access, agent permission and background execution. Enabling access allows inspection and reviewed creation, naming and individual task membership changes for native tags. Unrelated user tags and historical tag identities remain. Native tags are never deleted automatically.

Agents need the additional habitica.tags.write permission. Existing task or organization permission does not expand automatically. Background work needs the separate executor opt-in; an uncertain original result pauses gameplay until reviewed.
