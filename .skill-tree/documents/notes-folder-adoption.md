Status: local implementation and synthetic qualification; unpublished. Owners: Workspace transfer model/API, Notes validators, browser capture, Sync transfer review and existing migration MCP tools.

Schema2 notebooks carry folders and separate folder receipts. Transfer markers add optional imported folder baselines without fabricating accepted folder commands. Imported scope changes from the explicitly reviewed browser owner/Workspace to the exact cloud owner/Workspace. Source archives preserve original command bytes and hashes.

Exact folder collisions retain the existing cloud folder and archive conflicting source variants only through the existing explicit conflict policy. Notes referencing a conflicting source folder remain archived source variants; no association to an unrelated target folder follows. Conflicting project identity prevents ambiguous folder rebinding. Capacity, stale target revision, connection/Notes epoch and original review hash guards retain atomic acceptance.

Local format/owner/source validation precedes authority freeze. Current IndexedDB capture also compares the exact Notes inventory bytes inside the transaction; concurrent Notes changes refuse and roll back Workspace/Notes fences together. Unsupported folder source/format refuses rather than dropping metadata. Lost acceptance and acknowledgement recover the original transfer receipt; only matching acceptance establishes one cloud authority.

The existing transfer review shows exact retained folder IDs, names, revisions, tombstones, source/target counts, original receipt counts and current/historical note memberships. Existing MCP preview/accept/receipt tools share the review. `get_workspace_transfer_record` adds `folderReceipt`, requires independent Notes access, omits sourceWorkspaceId and returns the exact original source receipt. A separately hashed metadata template permits folder-receipt recovery after explicit Note body purge; original private Note bodies remain erased. Notebook deletion removes metadata and personal source fragments.
