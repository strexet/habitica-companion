- paragraph: Privacy
- heading "Data handling" [active] [level=1]
- paragraph: By default, Habitica credentials stay in this browser and are sent only to Habitica. Optional ChatGPT linking, cloud Notes or cloud workspace access requires separate consent to encrypted credential storage on the Companion integration server. Exports, private device sync, and shared party sync do not include your API token.
- heading "Optional cloud workspace" [level=2]
- paragraph: Cloud task storage requires its own explicit consent, independently of ChatGPT. The workspace server can read task names, notes, categories, projects, goals, saved views, completion history and commands. Enabling it also requires encrypted credential storage on the integration server. Private device sync retains its separate encrypted boundary.
- paragraph: Workspace task and command history remains until explicit workspace deletion. Disconnect revokes workspace sessions and pauses background execution while retaining that history. Delete cloud workspace removes cloud tasks and command history; it does not delete local browser copies, integration credentials, or Habitica records. Delete integration profile separately removes stored credentials. Background execution requires separate opt-in. Unaccepted command previews contain readable task fields, expire after ten minutes and are removed by bounded server cleanup. Accepted preview-to-command bindings remain with command history. Scheduler interruptions and hosting backups can delay physical removal. Local workspace backups are readable and contain no credentials.
- heading "Personal Notes" [level=2]
- paragraph: Browser Notes stay on this device and are excluded from private device sync and ordinary task backups. Markdown exports contain readable private text. Cloud Notes requires separate consent to server-readable titles, Markdown, up to sixteen prior versions and encrypted Habitica credential storage. Connected agents need separate Notes permissions. No conversation text is saved automatically.
- paragraph: Cloud notes and trash remain until explicit permanent deletion. Purging a note removes its current text and retained versions from active service tables while keeping content-free identity and receipt hashes. Disconnecting Notes blocks Notes sessions and agent access while retaining content. Integration disconnect also blocks Notes; deleting the integration profile deletes cloud Notes. Provider backups have their own recovery lifecycle. Browser copies and downloaded files remain separate.
- paragraph: Unaccepted agent Notes previews expire after ten minutes; bounded scheduled cleanup removes their text. Acceptance scrubs the preview body and retains content-free receipt metadata. Sign-out forgets tab connection credentials. Browser drafts are volatile and clear on account switch or sign-out.
- heading "Optional authenticated party planning" [level=2]
- paragraph: Authenticated planning has separate consent and stores readable quest selections, contributor labels, votes and receipts. Only opted-in current members can read shared planning. Browser-claimed legacy roles do not authorize this queue. Planning does not start quests or cast spells.
- paragraph: Shared records remain until explicit removal. Export or remove your own contributions through Settings, including after leaving a party. Removing your queued quests also removes votes on those quests. The verified current leader can delete the entire authenticated namespace. Cloud workspace deletion and credential deletion do not remove these separate shared records. Remove needed contributions before credential deletion, or revalidate in Companion to manage retained contributions later. Namespace deletion revokes planning consent and command access. Hosting backups can delay physical removal.
- heading "Optional ChatGPT linking" [level=2]
- paragraph: When linking is available, Settings asks for explicit consent before sending credentials to the Companion integration server. ChatGPT receives a separate OAuth grant; it never receives the Habitica API token. Disconnect removes stored credentials and denies integration access. Delete integration profile removes the profile record. Browser snapshots, Habitica data and ChatGPT conversations are separate.
- paragraph: Revoke ChatGPT access removes OAuth authority while retaining encrypted credentials and separate Workspace/background access. New tool and refresh calls reject revoked grants. Unaccepted task, spell and Cron previews lose authority; accepted commands and uncertain gameplay retain safety evidence. Pause the Workspace executor separately to stop future background work. Replacing the current tab management credential invalidates the old management bearer without changing ChatGPT permissions. Status shows bounded permission and credential-verification metadata; last ChatGPT authorization time does not represent background Workspace activity.
- paragraph: Linking codes expire within ten minutes. Operational audit metadata is limited to thirty days and excludes task text, credentials and conversation text. Hosting logs and backups have separate retention. Management credentials stay in the current tab and are excluded from exports and sync. Losing the management credential requires Habitica revalidation.
- heading "If the app looks out of date" [level=2]
- paragraph: Refresh to load the latest application version first. Before clearing site data, export any browser Notes and local workspaces you want to keep. Clearing site data also deletes their local copies.
- heading "Habitica credentials" [level=2]
- paragraph: Credentials are used to load your Habitica data and protect private device sync. They are not included in exports. Party sync uses a local party claim, so the API token is not sent to Cloudflare party-sync endpoints.
- heading "Local and exported data" [level=2]
- paragraph: Saved Habitica data, party history, app messages, gear information, and equipment presets are stored in browser storage. Downloaded backup files are readable, so keep them private.
- heading "Private sync" [level=2]
- paragraph: Private device sync stores encrypted data. Shared party sync stores party CRON history, derived party state, roles, settings, and kick records. Local party claims are token-private but trust-based. Hosting providers may process request details such as IP address and timestamps for security.
